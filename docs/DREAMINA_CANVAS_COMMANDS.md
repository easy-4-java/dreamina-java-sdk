# Canvas CLI 1.0.1 完整业务命令目录

来源：本机 `dreamina-canvas schema` 与逐项 `--help`。37 个业务入口，46 个命令/组描述。动态模型、音色不固化到枚举。完整
successData/dryRunData/constraints 见随包 schema。

| Java 枚举              | CLI 路径               | 用途                                                                        |

| `MODEL`                | `model`                | 查询生成模型及其可调用规格                                                  |
| `MODEL_LIST`           | `model list`           | 列出生成模型及可填写 flag                                                   |

## model

位置参数：name（可选；model 查规格时必填）（可重复）。

| 参数   | 类型   | 必填 | 默认 | 含义与约束                                                                   |
|--------|--------|------|------|------------------------------------------------------------------------------|
| `type` | string | 否   | —    | 资源类型：image、video 或 audio；省略时搜索全部生成类型；image\|video\|audio |

| 参数             | 类型     | 必填 | 默认 | 含义与约束                                                                                      |
|------------------|----------|------|------|-------------------------------------------------------------------------------------------------|
| `project-id`     | string   | 否   | —    | 项目 UUID；同时用作 draft-id；省略时使用当前项目；UUID                                          |
| `node-id`        | string[] | 是   | —    | 需要批准的节点 node_id，可重复传入                                                              |
| `credit-ceiling` | integer  | 是   | —    | 批准的积分消费上限；低于服务端最新报价总额时不签发；>=0; must cover the latest service estimate |

## node run

触发给定节点的运行。退出码：0, 2, 10, 11, 12, 13, 20, 21, 22, 1。

| 参数           | 类型     | 必填 | 默认 | 含义与约束                                                                                                                                                                           |
|----------------|----------|------|------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `project-id`   | string   | 否   | —    | 项目 UUID；同时用作 draft-id；省略时使用当前项目；UUID                                                                                                                               |
| `node-id`      | string[] | 是   | —    | 需要运行的节点 node_id，可重复传入                                                                                                                                                   |
| `submit-id`    | string[] | 否   | —    | 逐节点稳定提交 UUID，可重复传入并与 --node-id 按顺序对应；全部省略时自动生成；UUID; optional; count must equal node-id count; each value is also the operation status/wait reference |
| `credit-token` | string   | 否   | —    | 确认扣费后返回的 creditConfirmationToken；creditConfirmationToken issued by node confirm                                                                                             |

## operation status

查询一次生成操作状态。退出码：0, 2, 11, 12, 20, 21, 22, 1。

位置参数：operation-ref（必填）。

| 参数         | 类型   | 必填 | 默认 | 含义与约束                                                                                                                |
|--------------|--------|------|------|---------------------------------------------------------------------------------------------------------------------------|
| `project-id` | string | 否   | —    | 项目 UUID；仅在本地恢复记录丢失时需要，用于直接向服务端只读查询；UUID; only needed when the local recovery record is gone |

## operation wait

等待生成操作进入终态。退出码：0, 2, 11, 12, 20, 21, 22, 1。

位置参数：operation-ref（必填）。

| 参数         | 类型     | 必填 | 默认 | 含义与约束                                                                                                                |
|--------------|----------|------|------|---------------------------------------------------------------------------------------------------------------------------|
| `project-id` | string   | 否   | —    | 项目 UUID；仅在本地恢复记录丢失时需要，用于直接向服务端只读查询；UUID; only needed when the local recovery record is gone |
| `timeout`    | duration | 否   | 10m  | 最长等待时间；0 表示只查询一次                                                                                            |
| `interval`   | duration | 否   | 5s   | 轮询间隔                                                                                                                  |

## resource upload

上传本地图片、视频或音频并登记为项目资源。退出码：0, 2, 11, 12, 13, 21, 22, 1。

| 参数          | 类型   | 必填 | 默认 | 含义与约束                                                                                                                          |
|---------------|--------|------|------|-------------------------------------------------------------------------------------------------------------------------------------|
| `file`        | string | 否   | —    | 本地图片、视频或音频文件路径；与 --source-url 二选一；mutually exclusive with source-url                                            |
| `type`        | string | 否   | —    | 媒体类型覆盖：image、video 或 audio；省略时按扩展名判断；image\|video\|audio; overrides file extension                              |
| `source-url`  | string | 否   | —    | 服务端可访问的图片 URL；与 --file 二选一（仅图片）；image only; mutually exclusive with file                                        |
| `project-id`  | string | 否   | —    | 项目 UUID；省略时使用当前项目；UUID                                                                                                 |
| `resource-id` | string | 否   | —    | 资源 UUID 幂等键；省略时自动生成，跨进程重试须复用同一值；UUID idempotency key; generated when omitted; always echoed as resourceId |
| `name`        | string | 否   | —    | 素材展示名；省略时用文件名                                                                                                          |
| `import-kind` | string | 否   | —    | 登记意图：local_upload（默认）或 external_generated（外部平台生成产物导入）；local_upload \| external_generated                     |
