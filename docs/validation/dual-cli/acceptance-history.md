## 已实现的静态规则

坐标成对、清空与内容互斥、标签数量、规范节点标识、资源引用及导入关系、跨项目资源来源、音频默认 TTS 及模型/音色/引用组合、时间轴片段语法与顺序、图片超清默认 pro 及分辨率约束、文本内容显式传入、时间轴标题等。静态失败在进程启动前返回；动态资源类型、模型权益、余额与报价继续由官方 CLI 判断。

保留现有公共执行器、方法、Builder、默认行为及参数顺序。旧 CLI 的 additionalArgs 仍为显式原始参数扩展，不宣称该扩展的任意覆盖参数均有 Java 静态校验。

错误增加 reason/localStorage/serviceCode/requestId/traceId；保留原始输出和原任务身份。受理后 exit20 的不重提交用隔离进程测试验证。真实抠图的短等待返回 exit0，任务已完成，因此不把它记作真实超时恢复验收。旧 CLI 异常和日志移除完整命令行，避免泄露提示词及令牌。
