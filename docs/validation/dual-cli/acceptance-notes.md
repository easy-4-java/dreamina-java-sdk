## 兼容与发布修复

Boot 2.3 的父依赖管理会覆盖到 Jackson 2.11；已在 Java 8 SDK 使用兼容的字符串反序列化扩展点，保留拒绝隐式标量转换，避免链接 2.12+ 专有 API。三线 TokenBuffer 显式保留 BigDecimal，防止旧运行时将原始小数转为 double。失败与修复日志均保留。

Starter 4.0.x 的 Central 扩展移到显式 release profile，默认 Maven 4 发布使用已配置的阿里云私服。构建成功不单独作为发布成功，最终均核对远端 metadata、制品、校验和及实际消费结果。
