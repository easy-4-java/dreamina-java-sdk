用法：
  dreamina-canvas node edit [flags]
  dreamina-canvas node edit [命令]

可用命令：
  audio       编辑音频节点；--run 时保存、报价、按服务端要求批准并运行
  element     编辑Element 节点，不触发生成
  image       编辑图片节点，不触发生成
  text        编辑文本节点，不触发生成
  timeline    编辑时间轴，把多个素材按顺序拼接，不触发生成
  video       编辑视频节点，不触发生成

参数：
  -h, --help   显示 dreamina-canvas node edit 的帮助

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作

使用 "dreamina-canvas node edit [命令] --help" 查看某个命令的更多信息。
