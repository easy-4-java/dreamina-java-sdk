用法：
  dreamina-canvas node delete [flags]
  dreamina-canvas node delete [命令]

可用命令：
  confirm     明确批准指定批次，签发删除凭证；不删除节点
  status      只读查询该批次首次删除结果；不签发凭证、不删除节点

参数：
      --delete-token string   node delete confirm 签发的短期凭证；必须复用同一 --update-id
  -h, --help                  显示 dreamina-canvas node delete 的帮助
      --node-id strings       指定 Node ID，可重复或逗号分隔，按顺序去重；不支持 group
      --project-id string     项目 UUID；省略时使用当前画布
      --update-id string      稳定更新 UUID；省略时生成；确认和重试必须复用

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作

使用 "dreamina-canvas node delete [命令] --help" 查看某个命令的更多信息。
