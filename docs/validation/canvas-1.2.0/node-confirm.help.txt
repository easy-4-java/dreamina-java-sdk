用法：
  dreamina-canvas node confirm [flags]

参数：
      --credit-ceiling int   批准的积分消费上限；低于服务端最新报价总额时不签发
  -h, --help                 显示 dreamina-canvas node confirm 的帮助
      --node-id strings      需要批准的节点 node_id，可重复传入
      --project-id string    项目 UUID；同时用作 draft-id；省略时使用当前项目

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作
