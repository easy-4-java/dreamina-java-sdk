用法：
  dreamina-canvas auth [flags]
  dreamina-canvas auth [命令]

可用命令：
  account     读取当前登录账号
  login       登录即梦画布
  logout      退出当前 profile 登录
  refresh     刷新当前登录凭据
  status      读取本地登录状态
  wait        等待已启动的登录授权完成

参数：
  -h, --help   显示 dreamina-canvas auth 的帮助

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作

使用 "dreamina-canvas auth [命令] --help" 查看某个命令的更多信息。
