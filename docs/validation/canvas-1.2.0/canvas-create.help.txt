用法：
  dreamina-canvas canvas create <name> [flags]

示例：
  canvas create "新画布" --use
  # 不传 --use 时不会切换当前画布；后续写操作请显式传返回的 projectId

参数：
  -h, --help                显示 dreamina-canvas canvas create 的帮助
      --project-id string   客户端生成的画布 UUID；重试时复用同一值
      --use                 创建后设为当前画布

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作
