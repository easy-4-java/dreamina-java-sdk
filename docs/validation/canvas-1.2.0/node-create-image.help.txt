用法：
  dreamina-canvas node create image [flags]

参数：
      --clear-tags                    把节点标签完整集合清空
      --count int                     生成数量；以 model list 返回的 --count min/max 为准；固定多图模型须显式指定该数量 (default 1)
      --credit-ceiling int            批准的积分消费上限；--run 时报价超过它会在运行前停止
      --credit-token string           已批准的 creditConfirmationToken；--run 时使用
      --dry-run                       只做本地校验并输出计划；不连接服务端、不写草稿、不报价或扣分
  -h, --help                          显示 dreamina-canvas node create image 的帮助
      --import-kind string            节点导入类别：local_upload（挂本地上传登记的资源）或 external_generated（外部平台生成产物导入）；与 resource upload 的登记意图同一套词汇
      --interval duration             --wait 的轮询间隔；默认 5s (default 5s)
      --mode string                   图片生成模式：t2i（text-to-image，文生图）或 i2i（image-to-image，图生图）；提供生成参数时必须显式指定，纯元信息更新或清空生成配置无需传入
      --model string                  服务端登记的图片模型标识
      --node-id string                稳定 node_id；省略时生成
      --project-id string             项目 UUID；省略时使用当前项目
      --prompt string                 完整图片生成提示词；引用写成 {{node:node_xxx}}、{{res:resourceId}}、{{uri:value}} 或 {{vid:value}}，写字面 {{ 用 \{{ 转义；画布已有来源节点时优先使用 Node ID，保留上游连线；Resource ID 用于资产库等无来源节点的素材或用户明确要求冻结，不自动从节点产物提取
      --ratio string                  图片宽高比，例如 1:1
      --ref strings                   完整类型化引用集合：node:value、res:value、uri:value 或 vid:value，可重复传入；画布已有来源节点时优先使用 Node ID，保留上游连线；Resource ID 用于资产库等无来源节点的素材或用户明确要求冻结，不自动从节点产物提取
      --resolution string             图片分辨率，例如 1K
      --resource-id strings           本节点已有产物的资源 UUID，可重复传入；需同时提供 --import-kind local_upload 或 external_generated。多个视为同一批次内的候选，顺序即候选顺序，首个为主选。资源须已登记、状态成功且类型为图片
      --resource-source stringArray   跨项目资源来源：<资源 UUID>@<来源项目 UUID>；可重复，仅声明本次保存使用的资源
      --run                           保存后依次报价、批准并运行该节点
      --submit-id string              稳定提交 UUID；--run 或 --resource-id 时省略则生成，停顿后续跑或重试导入须复用它
      --tag strings                   颜色标签 ID，可重复传入；取值 default-tag-1..default-tag-5，除非用户明确指定标签否则不要默认传
      --timeout duration              --wait 的最长等待时间；默认 10m，0 表示只查询一次 (default 10m0s)
      --title string                  图片节点标题；纯保存时必填；带 --run 时省略则取非空 prompt 摘要，prompt 为空时必须指定；提供时不能为空，最多 512 个 UTF-16 code units
      --update-id string              稳定更新 UUID；省略时生成
      --wait                          --run 后等待该节点生成进入终态
      --x float                       节点左上角 X；组内为父组相对坐标；与 --y 成组提供
      --y float                       节点左上角 Y；组内为父组相对坐标；与 --x 成组提供

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作
