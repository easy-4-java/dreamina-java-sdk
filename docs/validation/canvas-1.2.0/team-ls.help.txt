用法：
  dreamina-canvas team ls [flags]

参数：
      --cursor string   上一页返回的不透明 nextCursor
  -h, --help            显示 dreamina-canvas team ls 的帮助
      --limit int32     单页条数，范围 1 到 100 (default 50)

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作
