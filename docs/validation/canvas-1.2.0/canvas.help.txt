用法：
  dreamina-canvas canvas [flags]
  dreamina-canvas canvas [命令]

可用命令：
  create      创建画布
  current     查询当前画布和实时权限
  ls          列举可访问的画布，只回定位摘要（projectId/name/createdAt/updatedAt/webUrl）
  use         核验权限并选择当前画布

参数：
  -h, --help   显示 dreamina-canvas canvas 的帮助

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作

使用 "dreamina-canvas canvas [命令] --help" 查看某个命令的更多信息。
