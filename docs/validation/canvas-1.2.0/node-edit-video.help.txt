用法：
  dreamina-canvas node edit video [flags]

参数：
      --clear-generation              清空 generationDraft
      --clear-tags                    把节点标签完整集合清空
      --count int                     生成数量；上限以 model list 返回的 --count max 为准 (default 1)
      --credit-ceiling int            批准的积分消费上限；--run 时报价超过它会在运行前停止
      --credit-token string           已批准的 creditConfirmationToken；--run 时使用
      --dry-run                       只做本地校验并输出计划；不连接服务端、不写草稿、不报价或扣分
      --duration float                视频时长（秒） (default 5)
  -h, --help                          显示 dreamina-canvas node edit video 的帮助
      --interval duration             --wait 的轮询间隔；默认 5s (default 5s)
      --mode string                   视频生成模式：t2v（text-to-video，文生视频）、first_last_frame（首尾帧）或 m2v（multimodal-to-video，多模态生视频）；提供生成参数时必须显式指定，纯元信息更新或清空生成配置无需传入
      --model string                  服务端登记的视频模型标识
      --node-id string                要编辑的节点 node_id；必填
      --project-id string             项目 UUID；省略时使用当前项目
      --prompt string                 完整视频生成提示词；引用写成 {{node:node_xxx}}、{{res:resourceId}}、{{uri:value}} 或 {{vid:value}}，写字面 {{ 用 \{{ 转义；画布已有来源节点时优先使用 Node ID，保留上游连线；Resource ID 用于资产库等无来源节点的素材或用户明确要求冻结，不自动从节点产物提取
      --ratio string                  视频宽高比，例如 16:9
      --ref strings                   完整类型化引用集合（node/res/uri/vid）；first_last_frame 传一个首帧引用，或按顺序传首帧、尾帧两个引用；画布已有来源节点时优先使用 Node ID，保留上游连线；Resource ID 用于资产库等无来源节点的素材或用户明确要求冻结，不自动从节点产物提取
      --resolution string             视频分辨率，例如 720P
      --resource-source stringArray   跨项目资源来源：<资源 UUID>@<来源项目 UUID>；可重复，仅声明本次保存使用的资源
      --run                           保存后依次报价、批准并运行该节点
      --submit-id string              稳定提交 UUID；--run 或 --resource-id 时省略则生成，停顿后续跑或重试导入须复用它
      --tag strings                   颜色标签 ID，可重复传入；取值 default-tag-1..default-tag-5，除非用户明确指定标签否则不要默认传
      --timeout duration              --wait 的最长等待时间；默认 10m，0 表示只查询一次 (default 10m0s)
      --title string                  节点标题；按 flag 出现更新
      --update-id string              稳定更新 UUID；省略时生成
      --wait                          --run 后等待该节点生成进入终态
      --x float                       节点左上角 X；组内为父组相对坐标；与 --y 成组提供
      --y float                       节点左上角 Y；组内为父组相对坐标；与 --x 成组提供

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作
