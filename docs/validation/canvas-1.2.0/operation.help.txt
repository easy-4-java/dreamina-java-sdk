用法：
  dreamina-canvas operation [flags]
  dreamina-canvas operation [命令]

可用命令：
  status      查询一次生成操作状态
  wait        等待生成操作进入终态

参数：
  -h, --help   显示 dreamina-canvas operation 的帮助

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作

使用 "dreamina-canvas operation [命令] --help" 查看某个命令的更多信息。
