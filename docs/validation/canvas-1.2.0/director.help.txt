用法：
  dreamina-canvas director [flags]
  dreamina-canvas director [命令]

可用命令：
  apply         原子应用场景、镜头、姿势、动画或分镜命令
  catalog       发现内置几何体、预设、人物或动作
  create        在画布上创建导演台节点
  export        导出截图或视频（需本机浏览器）或 FBX 动作
  freeze        把动画帧定格到摆拍（需本机浏览器）
  preview       查看当前镜头或分镜帧的截图（需本机浏览器）
  pull          读取画布导演台到新文件
  push          保存正文并原子更新画布版本
  resume-export 恢复中断的画布导出
  show          查看并校验画布或本地场景

参数：
  -h, --help   显示 dreamina-canvas director 的帮助

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作

使用 "dreamina-canvas director [命令] --help" 查看某个命令的更多信息。
