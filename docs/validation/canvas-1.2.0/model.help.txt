用法：
  dreamina-canvas model <name...> [flags]
  dreamina-canvas model [命令]

可用命令：
  find        按展示名或别名定位可调用的 canonical model
  list        列出生成模型及可填写 flag

参数：
  -h, --help          显示 dreamina-canvas model 的帮助
      --type string   资源类型：image、video 或 audio；省略时搜索全部生成类型

全局参数：
      --format string     输出格式：json 或 table
      --non-interactive   禁用交互提示
      --profile string    本地登录态隔离名称 (default "default")
      --region string     产品区域：cn；缺省 cn (default "cn")
      --yes               确认策略允许由参数确认的操作

使用 "dreamina-canvas model [命令] --help" 查看某个命令的更多信息。
